# Sistema de Apoyo a la Decisión Clínica para Condiciones Genéticas Pediátricas — Módulo de Interfaz de Usuario

## Descripción

Sistema de apoyo a la decisión clínica (CDSS) para la sospecha de condiciones
genéticas pediátricas mediante inteligencia artificial y análisis de datos
clínicos, desarrollado para el Hospital Regional de Cobán. Este repositorio
corresponde al **módulo de interfaz de usuario**: la capa con la que el personal
clínico captura datos del paciente, consulta las sugerencias generadas por el
modelo y revisa los resultados del análisis.
